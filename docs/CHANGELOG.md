# 变更日志

## v33.15（当前版本）

修复「实验室 · 自由拼装」里增加相贯体/面时卡顿 1.2~1.9 秒的问题。

### 根因

`SHAPES.lab` 是空白实验室（`R=1, H=1`），本来**没有主立体**，
但 `samplePoints()` 没有判断模式，仍然跑 `revBodyPoints()` ——
于是它在 2×1×2 的小盒子里撒出 **18,011 个「幻影点」**。这些点带来两个后果：

1. `splitByConnectivity` 的体素桶极密，27 邻域扫描退化成近似 O(n²)
   → 加一个相贯体/面就卡 1.2~1.9 秒；
2. 它们污染 `estimateSampleSpacing`，把采样间距从 ~3.1 拉低到 ~0.12，
   连通阈值随之降到 2.5（低于部件点云真实的 ~3.06 间距）
   → **一个圆柱部件被碎成 51 片伪块**。

这也解释了用户观察到的两个对照现象：
- 加「模型拼装」部件不卡 —— `addPart()` 只调 `buildParts()`，不经过 `refresh()`；
- 其他功能卡片不卡 —— 它们有真立体，采样点摊得开、体素桶稀疏。

### 修复

- **`samplePoints()`**：`if(SHAPES[shape].lab) return [];`
  实验室不再采主立体点（lab 里真正有意义的采样点只有 `partBodyPoints()`）
- **`splitByConnectivity()`**：
  - 体素键由字符串拼接改为整数键（三格坐标压成一个整数），
    省掉 1.8 万点 × 27 次查询的字符串哈希开销
  - 连通搜索改「先快后准」两段式：先用 ±1 格快扫，
    仅当发现多于一个分量时才按完整半径 `ceil(TH/voxel)` 复核。
    既保住单分量场景的零额外开销，又修掉「阈值比格子大、只搜 ±1 格
    导致漏连、把一大块切成几十片伪块」的既有缺陷

### 实测

| 操作（实验室 · 点选模式） | 修复前 | 修复后 |
|---|---|---|
| 加相贯体 | 1,262 ~ 1,282 ms | **19 ~ 47 ms** |
| 加面 | 1,819 ~ 1,902 ms | **7 ~ 38 ms** |

其他卡片未变慢，反而略快（如圆锥+相贯体 157→112 ms）。
实验室分块数从错误的 63 修正为 4（伪块消失）。

真实浏览器（Edge headless）复测：加相贯体 **1262.6 ms → 19.1 ms**，
加面 **1902.3 ms → 7.3 ms**；同场景前后截图像素差异仅 **0.26%**，
且差异只来自状态文字（`cells=63`→`4`），几何渲染一致。

### 说明

`tests/regions.js` 与 `tests/cellgeo.js` 各有一个失败，
是**本版之前就存在**的既有问题（穷举法把同一符号位区域算 1 块、
连通性分割拆成 2 块，导致「穷举数 7 ≠ 分块数 8」），与本次改动无关。

## v33

分块语义重写 + 相贯线精度 + 性能优化。这是一个较大的重构版本。

### 分块系统（「点选保留部分」）

- **自由拼装部件参与分块**：部件体积进入着色器裁剪（`uPartC/Q/D/K`），
  部件可被面/相贯体/其它部件切成子区域
- **部件四值码**（`0` 侧外 / `1` 顶外 / `2` 底外 / `3` 内部）：
  修掉「长方体横穿棱锥时，隐藏锥顶尖却连锥底一起隐藏」
- **相贯体四值码**：同上，修掉相贯体裁切时的同类问题
- **连通性分割**：同一符号位下不连通的区域用并查集拆成独立块
  （符号位无法表达「是否连通」，这是本版最核心的修复）
- **碎片过滤**：采样稀疏导致的假碎片并回主分量，避免伪块
- **分割平面**：用相邻分量间隙中点切分，外侧开口不设边界（不削掉锥尖）
- **`cellAtPoint(P)`**：射线检测不执行裁剪，必须用命中点反查真实归属的 cell

### 几何判定修正

- **`insideSolidWorld` 多面体判定**：原来用极坐标半径公式，
  但角度取 `atan2(z,x)` 而 three.js 顶点是 `x=R·sin, z=R·cos`，差 90° 相位。
  实测约 8.9% 采样点内外判错 → 改用半空间判定，误差降为 0%
- **正三棱锥内部判定**：原来用 `x²+z² ≤ r²`（这是圆锥），
  实际截面是三角形 → 改用真三角形判定
- **默认摆放方向**：`addPart` 默认类型从 `frontal`（水平）改为 `horiz`（竖直）

### 相贯线

- **棱锥表面采样**：原来只在 3 条棱中点方向各撒 1 列点，且相位用 `cos/sin`
  而几何体用 `sin/cos`，整块转 90° → 改为每个侧面单独铺网格，相位对齐。
  曲线点到表面偏差 **5.13mm → 0.00mm**
- **端面采样**：圆柱/圆锥/圆台补端面圆盘，修掉交线落在端面上时整段丢失

### 性能

- `selInherit` 记忆化 + 递归深度 4→2 + 命中即返回：**17.3s → 0.67s**
- `partInvOf` 缓存逆矩阵（按参数签名失效）
- `partBoundaryDist` 廉价距离粗筛
- 体素哈希加速连通性邻域查询

### 视觉

- 分块网格 `depthTest=false` + `renderOrder=1010+`，永远画在最上层
  （否则被同色的「贯体变实」相贯体盖住，点了看不出变化）
- 隐藏态 `opacity` 0.1 → 0.06，让「变暗」更明确
- 相贯体轮廓设 `hlKeep`，点选模式下保持可见（是相贯体唯一的把手）

### 测试

- 新增 `cellgeo.js`（分块裁剪互斥完备）
- 新增 `cylpick.js`（相贯体裁切点选）
- 新增 `tintpick.js`（贯体变实 + 点选遮挡）
- 新增 `eventflow.js`（真实 DOM 事件流，pointerdown@canvas → pointerup@window）
- 新增 `verify_geom.py`（纯 Python 独立几何验证）
- 新增 `test3/regions.js`（第二套独立 harness，union-find 计区域）
