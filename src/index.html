自建模型 (0) （各功能卡通用；点名字放进场景，拖住可移动）
还没有自建模型。在上面把实体处理好后，点左侧「存为自建」保存， 出来就能在这里点名字放置（暂时保存只在本页有效，永久保存下次进来还在）。
放出来的模型和拼装部件一样参与「点选保留部分」：切到点选模式后轻点它的某一块就能单独隐藏。 行里 №n ✕ 是"只收回这一个"，「收回全部」才一次清空。
说明：正平面∥V、水平面∥H、侧平面∥W；正垂面⊥V、铅垂面⊥H、侧垂面⊥W（角度=与水平面的夹角， 铅垂面角度=与侧立面W的夹角）。左右= X(+右)、高低= Y(+上)、前后= Z(+前)，单位 mm。 直接拖住彩色面片可沿法向平移；与其他平行面靠近共面位置会自动吸合（继续拖远即平滑脱离，不会卡住）， 也可吸附"过锥尖"、"底面所在平面"等特殊位置；面与任一模型（主立体 / 拼装部件 / 相贯体）的轮廓 恰好相交，或正好经过模型的轮廓特征点（棱、顶点、端面圆周）时也会吸附。 拖动拼装部件 / 相贯体时，与其它模型刚好接触（相切不重叠）同样会自动吸附（顶部提示条说明吸到了哪）。 "点选保留部分"：立体被启用的面分成几个部分时，直接点 3D 里想保留的部分之外的部分（变暗），即可只留想要的。 放出来的自建模型也一样：它和拼装部件同类，同样会被启用的面/贯穿体切开，切到点选模式后可以逐块点掉。
贯穿圆：和面一样分正平面/正垂面/水平面/铅垂面/侧平面/侧垂面六种——圆柱的轴就是该类型面的法向， 沿轴无限贯穿＝一个无限长圆柱（例：水平面型的贯穿圆＝竖直打孔）；它和面一样会把立体分开， 同样可在"点选保留部分"里点选留/不留。青色圆环永远画在立体前面，拖住即可移动，面板里可改角度/位置/半径。
用法两选一：实体相贯＝立体上贴一个半透明相贯体（看相贯线用）； 贯穿打孔（行内勾「贯穿」）＝直接在立体上挖出通孔，「显示全部 / 只显示交集」都能看到孔。 只有圆柱 / 正方体 / 长方体能贯穿打孔（孔壁按圆/矩形截面生成）； 圆锥、球、半球、槽、正三棱锥、圆台只做实体相贯，行内没有「贯穿」勾选。
左侧 交线＝面与立体表面的截交线（黄线）；相贯线＝贯穿体与立体的相贯线（绿线）。 两者都能"点线上任意位置看名称"，名称显示 2 秒后自动消失。 「点选保留部分」里轻点某一块就能单独隐藏它，隐藏状态会一直保留：再加面/贯穿体只会在原基础上细分， 已经隐藏的部分仍然是隐藏的（点「全部保留」恢复）。点选模式里也能按住圆环/面片拖动，只是拖动幅度要过 10px。
